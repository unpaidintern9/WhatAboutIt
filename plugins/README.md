# Plugins

Feature implementations live behind plugin contracts.

## Required Plugin Areas

- Recording
- Cameras
- Audio
- Timeline
- Auto Edit
- Export
- Teleprompter
- Themes
- Learning Center

## Rules

- Plugins must be offline-capable unless explicitly marked optional.
- Plugins must not leak technical engine terminology into user-facing copy.
- Plugins must provide test plans before implementation.
- Plugins must include learning hooks: walkthrough, help article, tooltip, search entry, and practice mode.
