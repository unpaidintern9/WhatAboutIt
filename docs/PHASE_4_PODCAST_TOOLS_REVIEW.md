# Phase 4 Podcast Tools Review

Review date: 2026-06-27

Brand Guardian score: 96/100

## Scope

Phase 4 adds podcast tools to the recording room:

- Teleprompter with script, sponsor script, speed, font size, readable mode, and pop-out view.
- Guest notes for questions, talking points, research, links, and don't-forget reminders.
- Sponsor notes with sponsor name, read script, talking points, disclaimer, and sponsor moment marker.
- Soundboard foundation for intro, outro, custom local slots, play/stop state, and volume.
- Live marker buttons with label, timestamp, optional note support, and recording session ID.
- Camera layout buttons with friendly layout names only.
- Practice Mode and Learning Center support for the new tools.
