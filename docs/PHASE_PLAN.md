# Phase Plan

## Phase 1 - Branded Offline Shell

Build the app's identity, storage model, and beginner-friendly episode creation workflow. Theme Engine files must drive the interface so branding is configurable instead of hardcoded.

Do not build live camera detection, mic detection, OBS control, media ingest, or export execution in this phase.

## Phase 2 - Devices + Studio Setup

Add device discovery and setup UX after Phase 1 is complete and visually approved.

## Phase 3 - Recording Engine

Integrate OBS/libobs behind a friendly recording control layer.

## Phase 4 - Podcast Tools

Add production tools that support recording day.

## Phase 5 - Timeline + Export

Add non-destructive review and export.

## Phase 6 - Smart Auto Edit

Add AI-assisted and signal-assisted editing as draft suggestions only.
