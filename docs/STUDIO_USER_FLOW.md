# Studio User Flow

Phase: 9E Real Studio Usability Pass

Status: implemented.

## Beginner Path

Studio Setup now guides a non-technical user through:

- Pick Camera 1
- Pick Camera 2
- Pick Camera 3
- Pick Morgan Mic
- Test Mic
- Go Record

The bottom of Studio Setup has one primary action: `Go to Record`.

## Record Screen Order

The first Record screen stack is:

- Live camera previews
- Mic meters
- Readiness strip
- Studio Ready summary
- Sticky Record/Pause/Stop controls

Notes, teleprompter, markers, soundboard, and camera layout controls remain available as secondary tools.

Per-channel gain, mute, solo, and monitor controls remain available behind `More` on each meter so the first screen stays calm.

## Helpful States

The studio uses plain language:

- `Pick a camera first`
- `Camera is being used by another app`
- `We need permission`
- `We can't hear you yet`
- `Use headphones to hear yourself safely`

## Guardrails

This phase did not change camera discovery, Sony preview handling, recording save/export, or long-recording behavior.
