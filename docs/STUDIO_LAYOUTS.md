# Studio Layouts

Studio layouts restore groups of pop-out windows with one click.

## Built-In Layouts

- Podcast Layout
- Interview Layout
- Solo Creator
- Dual Monitor
- Triple Monitor
- Custom

Each layout stores which panels are popped out, fullscreen state, collapsed state, and the saved monitor assignment when available.

## Using Layouts

Open Settings, then Studio Workspace. Choose a layout profile to restore it.

Recommended use:

- Podcast Layout: teleprompter, soundboard, and markers ready for a standard show.
- Interview Layout: fullscreen teleprompter with guest notes nearby.
- Solo Creator: teleprompter forward, soundboard and markers close.
- Dual Monitor: teleprompter and soundboard on the second screen.
- Triple Monitor: teleprompter, soundboard, and notes spread across displays.

## Launch Behavior

When Launch with saved layout is on, the app restores the selected layout on startup. Remember window positions controls whether each floating window returns to its previous size and monitor.

## Reset

Reset layout closes floating windows and clears saved window placement. It does not delete episodes, recordings, notes, markers, or soundboard data.
