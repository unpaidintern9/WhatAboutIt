# Camera Advanced Settings

Advanced settings live behind the gear icon on each camera card.

## Allowed Settings

- Connection type
- Resolution
- FPS
- Preferred camera
- Auto reconnect
- Battery warning if available
- Signal warning if available
- Forget camera

## UX Requirements

The gear menu must feel polished, short, and optional. It must not become the main setup path.

Use friendly values wherever possible:

- Signal: Good, Weak, Lost
- Battery: percent when available
- Resolution: Auto by default
- FPS: Auto or a simple number

## Brand Requirements

Use active theme tokens only. The menu should feel like part of What About It? Studio, not a generic settings panel.
