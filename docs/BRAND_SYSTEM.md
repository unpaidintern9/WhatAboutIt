# Brand System

What About It? Studio must never look like a generic Electron app, Bootstrap dashboard, Material UI demo, or developer tool.

The product should be recognizable as What About It? Studio from a screenshot because of its design language, not just its logo.

## Default Theme Direction

- Vintage Americana.
- Nashville recording studio.
- Warm, welcoming, and confident.
- Deep reds.
- Warm creams.
- Rich blacks.
- Leather.
- Aged paper.
- Brass accents.
- Subtle textures.
- Bold display typography.
- Handwritten accent typography.
- Large tactile buttons.
- Friendly conversational wording.
- Personality over corporate minimalism.

## Theme Engine Requirement

Branding must not be hardcoded. Every visual decision should come from theme files and, later, the visual Theme Editor.

Theme options include:

- Colors: primary, secondary, accent, success, warning, danger, background, surface, cards, buttons, icons, and audio meters.
- Typography: display font, heading font, body font, accent/signature font, sizes, weights, letter spacing, and line spacing.
- Branding: application name, logo, sidebar logo, splash screen, loading screen, export branding, and icons.
- Textures: paper, leather, wood, fabric, metal, flat, and none.
- Texture intensity: adjustable per theme.
- Components: button shapes, border radius, shadows, border styles, cards, navigation, hover animations, transition speed, and icon style.

## Built-In Themes

- What About It? (Default)
- Midnight Studio
- Clean Slate
- Cabin Sessions
- Nashville Neon
- Creator Mode

Users must eventually be able to create, export, import, and share custom themes.

## Visual Rules

- Do not use fake people photos.
- Do not generate fake Morgan or guest photos.
- Use branded placeholders, typography, color, icons, textures, and empty camera preview boxes.
- Large actions should feel tactile.
- Copy should feel friendly and plainspoken.
- Avoid generic admin dashboard patterns.
- Accessibility is part of visual quality.

## Definition of Done

Every new screen must:

- Match the active theme.
- Feel premium.
- Feel handcrafted.
- Feel approachable.
- Be easy enough for a first-time user.
- Avoid generic admin dashboard or boilerplate Electron styling.
