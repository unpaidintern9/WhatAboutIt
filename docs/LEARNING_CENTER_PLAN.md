# Learning Center Plan

Learn Studio helps Morgan and future users understand the app without leaving the offline desktop experience.

## Phase 1

- Placeholder screen.
- Friendly plain-language categories.
- Offline-only copy.

## Future Topics

- Starting a new episode.
- Setting up cameras and mics.
- Recording with confidence.
- Using markers.
- Reviewing Auto Edit suggestions.
- Exporting for YouTube.
- Exporting audio-only versions.
- Troubleshooting.

## Voice

Use friendly, conversational wording. Avoid jargon unless the app explains it immediately.
