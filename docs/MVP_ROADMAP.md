# MVP Roadmap

## Phase 1 - Branded Offline Shell

Deliver:

- Electron/React app scaffold.
- What About It? branding.
- Theme Engine foundation.
- Built-in theme files.
- Visual Theme Editor placeholder.
- Home screen.
- New Episode flow.
- Local project folders.
- Metadata JSON.
- Recent episodes.
- Settings.
- Learn Studio placeholder.
- Practice Mode placeholder.

Exit criteria:

- Morgan can open the app shell and create a local episode record.
- No network is required for the shell.
- All data is stored locally.
- The interface unmistakably follows the active theme.
- Phase 2 device detection is not implemented yet.

## Phase 2 - Devices + Studio Setup

Deliver camera detection, mic detection, preview boxes, audio meter UI, setup wizard, saved default devices, and friendly troubleshooting.

## Phase 3 - Recording Engine

Deliver hidden OBS/libobs control layer, start/pause/stop recording, up to 3 cameras, multiple mics, program recording, separate tracks where possible, and crash-safe backups.

## Phase 4 - Podcast Tools

Deliver teleprompter, second screen teleprompter, guest notes, sponsor notes, soundboard, intro/outro buttons, live markers, and camera layout buttons.

## Phase 5 - Timeline + Export

Deliver timeline viewer, trim/split/delete, marker timeline, non-destructive edits, FFmpeg export worker, YouTube MP4 export, audio-only export, and export progress.

## Phase 6 - Smart Auto Edit

Deliver Gentle, Balanced, Fast Paced, and Clip Hunter modes; silence removal; audio normalization; compressor/limiter preset; active-speaker camera switching; marker preservation; chapters; clip suggestions; edit report; review/accept/reject changes; and non-destructive draft timelines.
