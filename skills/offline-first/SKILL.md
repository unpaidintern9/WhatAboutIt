# Offline First Skill

Use this skill for storage, filesystem, persistence, and dependency decisions.

## Rules

- Core workflows must run without internet.
- Store project data locally.
- Store source dependencies inside this project root.
- Remote services may only be optional future additions.
- Avoid remote fonts, images, templates, or APIs for app boot.

## Required Local Files

Episode folders should contain metadata, media, drafts, exports, and reports subfolders.

## Definition of Done

- Launches offline.
- Saves offline.
- Recovers or explains local file issues clearly.
