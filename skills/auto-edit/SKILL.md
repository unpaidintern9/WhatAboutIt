# Auto Edit Skill

Use this skill for future Auto Edit modes and edit suggestion behavior.

## Rules

- Auto Edit creates non-destructive draft timelines.
- Original media is never modified.
- Suggestions must be reviewable.
- Edits must preserve markers.
- Phase 1 may only show disabled placeholders.

## Modes

- Gentle.
- Balanced.
- Fast Paced.
- Clip Hunter.

## Definition of Done

- Auto Edit helps without taking control away from the user.
