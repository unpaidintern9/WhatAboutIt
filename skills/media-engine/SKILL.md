# Media Engine Skill

Use this skill for OBS, FFmpeg, MLT, OpenCV, whisper.cpp, Essentia, and auto-editor research or integration.

## Rules

- Keep engines behind app services.
- Do not expose command lines to Morgan.
- Do not implement recording before Phase 3.
- Do not implement timeline/export before Phase 5.
- Do not implement Auto Edit before Phase 6.

## Definition of Done

- Media behavior is documented, local, recoverable, and hidden behind simple UI.
