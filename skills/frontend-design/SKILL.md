# Frontend Design Skill

Use this skill for UI, layout, interaction, copy, and theme implementation.

## Rules

- Never produce generic Electron, Bootstrap, Material UI, or developer-tool visuals.
- Use large tactile controls.
- Use friendly, conversational wording.
- Use active theme tokens for colors, type, texture, borders, shadows, and motion.
- Avoid fake photos.
- Use branded placeholders and empty camera boxes.
- Preserve accessibility and contrast.

## Definition of Done

- Screen matches active theme.
- Screen is recognizable as What About It? Studio.
- Screen feels premium, handcrafted, approachable, and easy.
- Brand Guardian review can pass.
