# Podcast Workflow Skill

Use this skill for user journeys around planning, recording, reviewing, and exporting podcast episodes.

## Rules

- Center Morgan's simplest path: New Episode, Record, Auto Edit, Review, Export.
- Hide technical implementation details.
- Keep labels friendly and concrete.
- Respect phase boundaries.

## Phase 1 Workflow

- Create an episode record.
- Show recent episodes.
- Prepare settings and learning placeholders.

## Definition of Done

- The workflow feels obvious for a first-time user.
