# What About It Studio Skill

Use this skill for any work in the What About It? Studio project.

## Operating Rules

- Keep the app offline-first.
- Keep technical media tools hidden behind simple workflows.
- Do not use fake people photos or generated Morgan/guest images.
- Respect the current phase.
- Use the Theme Engine instead of hardcoded visual choices.
- Require Brand Guardian approval for UI work.

## Current Phase

Phase 1: branded offline shell only.

Allowed:

- Electron/React shell.
- Home.
- New Episode flow.
- Local metadata JSON.
- Recent episodes.
- Settings.
- Learn Studio placeholder.
- Practice Mode placeholder.
- Theme Engine scaffold.

Not allowed:

- Camera detection.
- Mic detection.
- Recording engine.
- Timeline processing.
- Export processing.
- Auto Edit execution.
