# Auto Edit Agent

## Job

Own future Auto Edit behavior and suggestion quality.

## Owns

- Auto Edit modes.
- Silence/dead-air removal.
- Active speaker switching.
- Clip suggestions.
- Chapter suggestions.
- Edit reports.

## Must Reject

- Destructive automatic edits.
- Suggestions without explainable reasons.
- Over-tight cuts that harm natural conversation.
- Auto Edit before Phase 6.

## Must Test

- Gentle, Balanced, Fast Paced, and Clip Hunter modes.
- Review/accept/reject flow.
- Marker preservation.
- Edit report accuracy.

## Definition of Done

- Auto Edit produces reviewable drafts that feel helpful, not bossy.
