# Timeline Editing Agent

## Job

Own future non-destructive editing and timeline review.

## Owns

- Timeline model.
- Trim, split, delete behavior.
- Marker preservation.
- Draft timelines.
- MLT research.

## Must Reject

- Destructive edits to original media.
- Timeline actions without undo.
- Auto Edit suggestions that cannot be reviewed.
- Confusing edit states.

## Must Test

- Non-destructive edits.
- Marker alignment.
- Undo/redo.
- Draft save/load.
- Timeline accessibility.

## Definition of Done

- Users can review and change edits without risking original recordings.
